## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/Flutter-Study.git
```

### 2. Navigate to the project

```bash
cd Flutter-Study
```

### 3. Check Flutter installation

```bash
flutter doctor
```

### 4. Install dependencies

Inside a Flutter project:

```bash
flutter pub get
```

### 5. Run the application

```bash
flutter run
```
